A one-star review written by a house cat about its human, for the make.fun bounty "Make the AI Judge Laugh: Cat Reviews Its Human". `main.py` (Python standard library only, no network) writes a single funny one-line review to `/output/entry.txt`. The complaint is specific — the human watches the cat eat as if dinner were a performance — and the sting lands in the last few words: "The food was adequate. The audience was not."

## Run it

```sh
python3 main.py
```
